# Visual UI Reference Pack (`ui-v3`) — All `13` Approved Screens (`Phone-First` Primary)

This directory holds all **13 visual UI references** governing **JELET Study Hub (v3)**, organized strictly by **Phone-First Priority**:

1. **Primary Tier — `10` Phone-First Screens (`<768px` Portrait Mobile Web PWA):**
   * **`01` – `07`:** Owner-supplied Phone UI foundation screens (`You/Settings`, `Papers`, `Results`, `Practice`, `Lesson`, `Learn`, `Today`).
   * **`11` – `13`:** Owner-selected v3 Phone-First screens completing the mobile UX (`Live Timed Exam + Slide-Up OMR Sheet`, `CodeC BYOK AI Tutor Bottom Sheet`, and `You & AI + JU CGPA Check`).
2. **Secondary Tier — `3` Desktop Progressive-Enhancement Screens (`≥1024px`):**
   * **`08` – `10`:** How the exact same tokens and components expand via `@media (min-width: 1024px)` on laptop/PC monitors (`Dashboard`, `Split OMR Exam Runner`, `Split Results + Docked AI Tutor`).

> **CRITICAL RULE FOR CODING AGENTS:** Always build **Phone-First (`360px–430px`)** matching `01`–`07` and `11`–`13` first, then layer `@media (min-width: 768px / 1024px)` for `08`–`10`. Whenever illustrative numbers/labels inside any PNG conflict with `docs/01-PRODUCT-AND-EXAM-SPEC.md` or `AGENTS.md`, **the written specification wins 100% of the time**.
