  air-gap power 1 : s : (1−s) split) → speed control.

  voltage-divider/current-divider pair → superposition → Thevenin/Norton with
  R_th for P_max (R_L = R_th) → star-delta → first-order RC/RL transients
  (τ = RC or L/R; 63.2%/5τ) → MPT caveat (50% efficiency).
- E06 covers semiconductor physics to rectifier practice: intrinsic/extrinsic
  (p₀n₀ = n_i², p₀ = 2.25×10²⁰/2.25×10¹⁵ = 10⁵ cm⁻³) → p-n junction depletion/
  barrier → diode V-I (forward/reverse) → rectifiers (HWR 40.6%, FWR 81.2%,

- E07 covers op-amps: ideal traits (A → ∞, CMRR → ∞) → inverting/non-inverting
  gain laws (−Rf/R₁; 1+Rf/R₁) → virtual ground → CMRR dB math
  (20·log₁₀(10⁵) = 100 dB) → saturation clipping (gain-10 at ±12 V rails)
  → slew-rate f_max = S/(2πV_p) ≈ 15.9 kHz → basic linear applications.
- E08 covers digital machinery: unsigned vs 2's-complement ranges (−128..+127)
