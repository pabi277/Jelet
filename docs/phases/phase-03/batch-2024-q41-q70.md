## Notable findings

1. **Withdrawn Q49:** the correct heat current is $kA(t_1 - t_2)/2l$, which no option gives. **Withdrawn Q58:** both the 64 km approximation and the exact 64.98 km fall between the printed options. Both items award +1 mark (+12 twelfths) to every candidate, and the solutions show the full analysis.
2. **Q61 and Q66 had spoiler stem figures on `main`** (Q66 drew the answer line). The booklet prints only option graphs, so both now have `stemFigure: null` with four option figures each. The verifier rejects any reintroduced stem figure.
3. **Q67 interpretation:** (D) $\mu = a/g$ satisfies $\mu \ge g/a$ only when $a \ge g$. It is judged false as a general statement, so the official key {B, C} is kept. Logged by G4 as an interpretation note.
4. **Notation quirks, kept verbatim:** the Q56 stem asks for the "frequency" but every option is an angular frequency ω. The Q61 graphs label the fall time with lower-case $h$ while the stem uses $H$. The Q45 options are given in θ, which is defined only by the figure (θ at C, measured from the diameter through O).
5. **Q68 precision redraw:** the booklet's hand sketch makes B about 10 % wider than A (61 vs 56 px in the scan), but the stem says A and B are identical. The outline now has equal A/B widths and a C leg about 1.32× wider (the booklet's average C/A ratio). Moved vertices slide along their adjacent edges, so the junction stays sharp. The verifier asserts |w_A − w_B| < 3 % and w_C > 1.2 w_A.
