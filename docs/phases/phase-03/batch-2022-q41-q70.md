# Phase 03 · JELET 2022 Batch B (`Q41`–`Q70`, Physics): Verification Record

**Branch:** `arena/5a50b1ca-jelet` · **Scope:** 2022 Paper-I Set A, Physics Q41–Q70 (**Cat-I Q41–Q65, Cat-II Q66–Q70**, as printed) · **Date:** 2026-11-24

**Source:** the same official JELET 2022 Paper-I Set-A booklet used for Batch A. It is a 24-page scan with no text layer, kept in the gitignored `.cache/pdfs/2022.pdf` with 180-DPI renders in `.cache/pages_2022/`. Physics pages **p11–p18** were each read visually before `q2022.py` was edited, and every diagram and option graph was checked again in zoomed crops. No PDF or PNG is committed.

**Answer key: verified-derived, not official.** As in Batch A, the 2022 official key is not archived anywhere reachable. Every Q41–Q70 key is derived by solving the booklet item independently, then re-deriving it in SymPy (`_b22_qN`), which judges all four options. Per-question `keyTier` is now `"verified-derived"` for Q1–Q70, with `sourceRef` set to `SymPy re-derivation _b22_qN (Set A, QN)`. The paper-level `keyTier` stays `"derived"` until Batch C (Q71–Q100) is done.

**Category split:** the booklet prints the Physics Cat-II header (2 marks, partial credit) **above Q66**, not Q61. Q41–Q65 are therefore single-correct Cat-I (1 mark, −¼) and Q66–Q70 are Cat-II. The data already used this split, and the verifier now asserts it (tamper "Q61 category 1 → 2" is caught).

## Decisions

| Item | Decision |
| :--- | :--- |
| **Q48** | **Key D, with an interpretation note (not withdrawn).** The printed options have no square root: each is dimensionally ω², even though they are labelled "rad/sec". (D) $\tfrac{4mg}{(2m+M)R}$ equals ω² exactly (energy conservation with drop $R$, $I = \tfrac12MR^2 + mR^2$), and no other option matches ω or ω². Q48 is **not** added to the voided list, so 2022 still has 1 withdrawn item (Q7). |
| **Q62** | **Key C.** In the booklet's V–T diagram, line AB extended meets the T-axis at ≈0.54 T_A rather than at O. Taken literally, P would fall along A→B, which matches graph A. AB is read in the standard textbook sense (V ∝ T, isobaric), followed by isochoric BC and isothermal CA, which gives graph C. G4 logs both the literal and the intended readings. |
| **Q69** | **Key ABCD.** (A) names I₂, the mirror's image of the virtual object I₁, located 10 cm left of the lens as marked in the figure. Strictly, the reflected rays reach the lens before they converge, so I₂ is never actually formed: it acts as a virtual object for the lens. This is recorded as an interpretation note. |
| **Q42** | The old data attached an **invented figure** (`fig-2022-q42.svg`). The booklet prints no diagram for Q42, so the SVG is deleted and `stemFigure` is null. The verifier asserts this, and the gate tamper that restores the file is caught. |

## Interpretation notes (printed by G4)

- **Q42:** "most probable error" is read as the school maximum-error rule (0.03 cm³). The quadrature value 0.017 cm³ is not printed.
- **Q48:** the radical is missing (see the decision above).
- **Q59:** "focal length of the system" means the lens + liquid-lens combination, giving μ = 1.6. The equivalent-mirror reading gives 1.8, which is not printed.
- **Q62:** AB does not pass through O. Literal match: A; intended match: C.
- **Q69:** I₂ is a virtual object, not a formed image.
