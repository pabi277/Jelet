## Interpretation notes (printed by G4)

- **Q18:** x = −1 also has slope 3, but it is end point A, and its tangent coincides with chord AB. Only x = 1 gives a distinct parallel tangent. (A) is unconditionally true, so it is the single Cat-I answer.
- **Q32:** see the owner decision above.
- **Q33:** uses the conventional roots $x = \operatorname{cis}\theta$, $y = \operatorname{cis}\phi$. Taking the conjugate root for $y$ swaps θ+φ and θ−φ, which would make (D) true instead.
- **Q34:** "eccentricity of the ellipse" is a misprint for the hyperbola in the stem.
- **Q37:** the printed $\tfrac{y}{9}$ is a misprint for $\tfrac{y^2}{9}$. The literal parabola has the single slope-1 tangent $y = x + \tfrac{85}{9}$, which matches no option.
- **Q39:** (B) differs from (A) by the constant $-\pi/\sqrt2$, so both are valid $f(x)$.
- **Q40:** both branches $y = 1 \pm \sqrt{1 - x}$ pass through (1, 1).
