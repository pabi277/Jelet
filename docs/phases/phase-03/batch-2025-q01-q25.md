## What changed

| Area | Change |
| :--- | :--- |
| `scripts/_build/q2025.py` | `Q1`–`Q25` stems and options were re-transcribed word for word and symbol for symbol from the rendered pages. Several earlier OCR stems were wrong (for example Q2 used a zero matrix, Q5 used `\sqrt{xy}`, Q6 had no limits, Q10 had `x + e^{x}`, Q12/Q17/Q21/Q23/Q24/Q25 were garbled). Q21's unit changed from `M01` to `M02` because it is a determinant evaluation. |
| `scripts/_build/s2025_batch1.py` | New file. It holds hand-written step-by-step derivations for `jelet-2025-q001`…`q025`, all as raw strings. These replace the old placeholder "Given key (X)" entries in `build_solutions.py`. |
| `scripts/verify_solutions_sympy.py` | Adds 25 independent SymPy re-derivations. Each one (a) checks that a fingerprint of the exact `stemLatex` is present, (b) recomputes the answer, (c) tests it against SymPy encodings of all four options, and (d) requires the matching option to equal `key.correct`. Tampering tests confirmed that a changed stem or a changed key makes the gate fail. |
| `scripts/verify_corpus.py` | Adds gate 9. It parses every `_data/**/*.json` file with `json.loads` and rejects `[\x00-\x08\x0b\x0c\x0e-\x1f\t]`. It also rejects any CR, and any LF directly followed by a letter (a swallowed `\right` / `\neq` / `\nu`). |
| LaTeX escapes | 118 single-backslash LaTeX escapes were fixed in `q2022–q2025.py`, `build_solutions.py` and `build_units.py`. Before the fix there were 45 control-character hits in the generated JSON (`\v`ec, `\t`an/`\t`ext, `\b`egin/`\b`ar, `\a`lpha, `\f`rac). Afterwards there are 0, and 0 Python `SyntaxWarning`s. |
| Figures | All 58 SVGs in `_data/figures/{2022..2025}` now use `var(--fig-*)` tokens instead of hex colours. The tokens are defined in `assets/css/tokens.css` for Light (`#FFFFFF`) and Dark (`#070C0C`), and every text/stroke token has at least 4.5:1 contrast in both themes. The figures must be inlined into the page to pick up the theme. |
| `index.html` | The two icon wrappers changed from `<span class="ico">` to `<svg class="ico" aria-hidden="true">`. |
