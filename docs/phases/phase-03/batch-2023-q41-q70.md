## Findings

- **The old Q41–Q70 text was corrupt OCR in 25 of 30 items.** Several items could not be answered as stored. Examples: Q41 had two identical options, Q48's options did not contain the right γ, Q61 had symbolic options instead of the printed coordinates, and Q64's energy levels gave a different answer. The keys were right, so all 30 items were rebuilt from the scan. The 30 old auto-generated solutions were replaced.
- **Q46 is withdrawn.** v_cm = (6(5, −2, 10) + 4(10, 2, 5))/10 = (7, −2/5, 8). Option B, 7î − 2ĵ + 8k̂, is the closest, but the ĵ component is −0.4, not −2, so no printed option is correct. The item awards +1 mark (+12 twelfths) to all candidates; this is never shown as "0 marks".
- **Q54 key dispute (official key kept).** Two equal-amplitude SHMs that always pass each other at x = A/2 moving in opposite directions must have phases 30° and 150° there, so the phase difference is 120° (or 240°). Neither value is among 210°, 30°, 90° and 180°. With a phase difference of 180°, the particles would pass only at x = 0. The official key `JEEB/Reg-267/23` lists D. G4 pins `official_key = ["D"]`, requires SymPy to find no printed option true, and prints the dispute. The tamper test that changes option A to 120° is caught.
- **Q57 interpretation note.** "Half that due to I′ alone" fixes the magnitude only. If the net field points along I′'s field, I/I′ = 1 (1 : 1, D). The reversed case gives I/I′ = 3, i.e. 3 : 1, which is not printed (option A is 1 : 3). The official key D is kept.
- **Q66 interpretation note.** (A) "The energy is conserved" is read as the work–energy balance W_F = ½kx² + ½mv² on a frictionless surface. It is not read as constant block–spring mechanical energy, because F does work on the system. The official key ACD is kept.
- **Unit remaps:** 11 items moved (see the table above). The other 19 unitIds already matched the real topics. The syllabus has no electrostatics, magnetism, nuclear or wave-optics units, so the closest unit was used (E01 for magnetic effects, E04 for electrostatics/DC, P15 for modern physics, P13 for wave optics).
- **SVG readback tolerances.** Figure coordinates are rounded to 0.1 px, so two checks needed robust estimators:
  - **Q48:** the per-point exponent near the end of the adiabat is noisy. The check uses a log–log regression through C over the curve samples (fit 2.7094 vs exact 2.7095, tolerance 0.01). A straight-chord tamper gives 3.181 and is caught.
  - **Q61:** the rounded maxima of the curve tie, so the check uses the mean x of the top plateau (y within 0.05 px of the top). Moving the M-line to x = 120 is caught.
