## Findings

- **The old Q1–Q40 text was corrupt OCR in about 27 of 40 items.** Several stems were unsolvable as stored. Examples: old Q16 "$\lim\frac{f(x+h)-f(x)}{h^2}=3$", old Q27 "$x\,d\Phi=\Phi\,d(y/x)$", old Q40 "the solution of $\frac{dv}{du}$". The keys were right, so all 40 items were rebuilt from the scan. The 40 old auto-generated solutions ("Identify the problem type … Apply the method …") were replaced.
- **Q6 is withdrawn.** The determinant is −(k+1), and the only singular value, k = −1, makes rows 1 and 3 read x + y + z = 1 and x + y + z = 4, which is inconsistent. So no real k gives infinitely many solutions, and none of 0, 3, 2, −2 does. The item awards +1 mark (+12 twelfths) to all candidates; this is never shown as "0 marks".
- **Q34 key dispute (official key kept).** Twice the area is |4t − 4|, so area 5 gives t = 7/2 *or* t = −3/2. Option (A) (−3/2, 3/2) lies on y = x + 3 and gives area ½\|−6 − 4\| = 5, exactly like (D). The official key `JEEB/Reg-267/23` lists only D. G4 pins `official_key = ["D"]`, requires SymPy to prove the extra option A true, and prints the dispute. The solution explains that, under the official key, marking A as well scores 0.
- **Q8 interpretation note.** The expression is cyclic, so labelling (a − 1, b − 1, c − 1) = (−3, −3ω, −3ω²) gives 3ω² (D), and swapping b and c gives 3ω (C). The key takes the conventional labelling. Options 0 and 3 are never attained.
- **Q40 interpretation note.** (D) "xy = cy + c₁ (c, c₁ arbitrary)" satisfies the equation only when c₁ = c². It is read as the printed form of the general solution. (A) y = 0 is a branch of the singular solution y(y + 4x) = 0, not a solution curve in the (u, v) plane on its own. The official key ACD is kept.
- **Unit remaps:** Q3 M02 → M01, Q4 M03 → M02 and Q5 M05 → M04. The other 37 unitIds already matched the real topics.
- **Performance trap avoided.** Brute-forcing $(\frac{\sqrt3}{2}+\frac i2)^{2007}$ with `expand_complex`, or integrating up to $e^{2007}$ directly, hangs SymPy. Instead, the checks use De Moivre (2cos(2007π/6)) plus a 60-digit mpmath cross-check, and the u = log x substitution with the integrand identity verified. The whole Batch A suite runs in about 3 s.
