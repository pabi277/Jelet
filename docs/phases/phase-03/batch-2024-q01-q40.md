## Findings

- **The old Q1–Q40 text was garbled OCR.** Stems and options belonged to different problems (the old Q1 solution was the 2025 quartic), although the key letters were right. All 40 were rebuilt from the scan. The three legacy 2024 checks (Q20, Q22, Q37) verified those corrupted stems, so they were removed rather than repaired. The 2025 Q22 check, which depended on a 2024 helper, was inlined.
- **Q4 unit remap.** M09 → M02, the only remap in this batch.
- **Q36 (B) wording, an interpretation note rather than a dispute.** "Continuous in ℝ but not derivable in ℝ" is read as "not derivable anywhere", which is false because f is derivable at every x ≠ 1, 2. Under the weaker reading, "not derivable at every point of ℝ", it would be true. The official key A, C is kept, and G4 prints this note in the dispute log.
- **Q40 has two roots.** The system $(1-p)q=\frac{2}{15}$, $p(1-q)=\frac16$ has two valid solutions: P(B) = 1/6 (with P(A) = 1/5) and P(B) = 4/5 (with P(A) = 5/6). That explains the key BC.
- **Q32 counter-example.** The rows (1, 0, 0), (1, x−a, 0), (1, 0, x−a) give det = (x−a)². So (x−a)² divides det A, but (x−a)³ is not forced, and (C) is not implied.
- **Q31 (C).** BA = θ holds for any idempotent A, including the non-symmetric $\begin{pmatrix}1&1\\0&0\end{pmatrix}$. No symmetry is assumed.
- **Q1 counter-example.** A rotation $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ plus a reflection diag(1, −1) is neither symmetric nor orthogonal, so only "singular" (A) is forced.
- **Gaps found by tamper testing and closed.** In the first tamper round, two mutations passed every gate:
  1. **Q19 option A changed to 25/48** (the old OCR duplicate). The check had the option values hard-coded, with no binding to the printed text.
  2. **Q4 paper `unitId` reverted to M09.** No gate compared a paper `unitId` with the unit files.

  Fixes: `enc=` option-value binding plus a distinct-options assertion for all 15 numeric Cat-I/II checks in G4, and gate 11 (unit-mapping consistency) in G3. Both tampers are now caught.
